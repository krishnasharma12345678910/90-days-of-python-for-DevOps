
# 90 Days of Python for DevOps

Daily Python practice as part of my journey to becoming a DevOps Engineer. Each day covers 5 small, hands-on problems built around core Python concepts, moving toward real DevOps automation skills (file handling, scripting, cloud automation).

---

## Day 1: Variables, Operators & String Basics

**Q1: Variables & f-strings**
Created variables for name and age, printed them together using an f-string.

**Q2: Arithmetic Operators**
Performed addition, subtraction, multiplication, modulo, and floor division on two numbers.

**Q3: String Basics**
Found the length of a string and converted it to uppercase and lowercase.

**Q4: Prime Number Check**
Checked whether a given number is prime using a loop and a boolean flag (`is_prime`).

**Q5: Max & Min in a List**
Found the maximum and minimum values in a list of numbers by looping through and comparing.
